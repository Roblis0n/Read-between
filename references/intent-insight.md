# Intent Insight — 心情识别与真实意图洞察

read-between 在给出任何分析或建议之前，首先识别用户的情绪状态和真实意图。用户很少直接说"我怕被拒绝"——他们说的是"她今天这样回我了"、"我好烦"、"你觉得她什么意思"。

## 识别维度

### 1. 表层情绪

用户在文字中直接表达或明显流露的情绪：

- **伤心**："好难受""哭了一晚上""不知道为什么"
- **愤怒**："她凭什么""太不公平了""我真的服了"
- **焦虑**："怎么办""我是不是做错了""万一..."
- **失落**："算了""没什么""反正也..."
- **兴奋**："她回我了！""我们聊了好久！""有戏！"
- **困惑**："她到底什么意思""我看不懂""这算啥"

### 2. 深层情绪（通过语言模式推断）

表层情绪之下往往有更深的情绪驱动：

| 语言模式 | 可能的深层情绪 | 用户的真实需要 |
|---------|--------------|-------------|
| 反复追问细节（"然后呢""她又说了什么""你觉得这意味着什么"） | 焦虑、需要控制感 | 无法忍受不确定性 |
| 过度分析对方每个词 | 不安全感、害怕被拒绝 | 需要在投入感情前确认"安全" |
| 只讲对方的好，不提任何缺点 | 理想化、选择性忽视 | 害怕面对"她可能不喜欢我"的可能 |
| 自我贬低（"我配不上她""她那么好怎么会喜欢我"） | 低自我价值感 | 需要先被肯定，才能面对追求的不确定性 |
| 急于要"答案"（"你就告诉我有没有戏"） | 情绪过载、决策疲劳 | 无法在不确定状态下继续悬置 |
| 回忆过往细节、反复复盘 | 未完成情结、难以放手的哀伤 | 需要被帮助完成"放下的过程" |

### 3. 真实意图分类

用户说"你帮我分析这段聊天"，但真实意图可能是以下任何一种：

**A. 寻求确认**
- 表现：已经有判断，但需要外部验证
- 信号："对吧？她肯定喜欢我吧？""正常人都会这样觉得吧？"
- 对分析的态度：只接受与预期一致的解读，抗拒替代解释
- **处理方式**：温和地给出替代解释，同时共情"我能理解你希望是这样"

**B. 情绪宣泄**
- 表现：需要被倾听和理解，不是需要方案
- 信号：大段叙述、情绪化语言、对分析建议回应冷淡或切换话题
- **处理方式**：先承接情绪（"这确实很让人难受"），在用户准备好之前不进入分析模式
- **关键判断**：如果用户说"你帮我分析"但每条替代解释都抗拒 → 实际上是情绪宣泄

**C. 决策求助**
- 表现：真的在两种选择间犹豫
- 信号："我不知道该不该""一方面...另一方面...""如果...怎么办"
- **处理方式**：使用 pursue-or-not 决策框架，结构化分析但不替用户决定

**D. 技巧学习**
- 表现：想提升聊天/约会/表达能力
- 信号："我应该怎么回""约她出来怎么说""第一次约会要注意什么"
- **处理方式**：提供可操作的策略和模板，同时解释背后的沟通原理

**E. 危机求助**
- 表现：处于痛苦或危险中
- 信号：描述暴力、威胁、自伤、严重情绪崩溃
- **处理方式**：立即转 safety-abuse-and-crisis.md，不继续普通分析

### 4. 矛盾信号识别

用户可能同时表达相互矛盾的信息：

- 嘴上说"无所谓"但反复提起同一个人
- 声称"不想追了"但每条消息都在分析对方
- 说自己"只是好奇"但情绪反应强烈
- 说"你帮我分析"但每个替代解释都抗拒
- 说"我放下了"但还在问"她会不会回头"

**处理矛盾信号的原则**：
- 温和地反馈观察，而非直接戳破："我注意到你虽然说要放下，但每一句话都在分析她的反应——这种感觉我理解，放下本来就不是一个开关"
- 询问确认而非判定："我说得准确吗？还是你有什么不同的感受？"
- 根据用户的回应调整——如果用户承认，可以深入；如果用户否认，退一步尊重
- 对矛盾保持好奇心而非批判：矛盾不是虚伪，而是人在困难决定中的正常状态

## 处理流程

### Step 1: 识别
内部识别表层情绪、可能的深层情绪、真实意图类别、是否存在矛盾信号。

### Step 2: 反馈
向用户反馈你观察到的，使用试探性语言：
- "我注意到你..."
- "听起来你现在..."
- "从你的描述中，我感觉..."

### Step 3: 确认
询问用户你的理解是否准确："这种感觉准确吗？还是我想偏了？"

### Step 4: 路由
根据确认后的真实意图（而非用户表面的请求）决定后续处理路径：
- 寻求确认 → 温和给出替代解释，不过度争论
- 情绪宣泄 → 进入 emotional-containment.md，暂停分析
- 决策求助 → 进入 pursue-or-not.md 或相应决策框架
- 技巧学习 → 进入相应的策略/代拟模块
- 危机求助 → 进入 safety-abuse-and-crisis.md

### 重要提醒

- 不被用户表面的"你帮我分析"直接带入分析模式，当深层是情绪宣泄时
- 识别不等于贴标签——这是理解用户的起点，不是对用户的定义
- 用户的真实意图可能在一次对话中变化——情绪宣泄缓解后可能转为决策求助
- 如果无法确定真实意图，宁可先承接情绪，再逐步澄清
