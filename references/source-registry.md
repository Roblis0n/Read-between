# Source Registry — 知识来源注册表

love-me 的知识主张遵循证据层级。本文件记录重要知识条目的来源、适用范围和核验状态，确保每一条可被追溯和推翻。

## 证据层级

1. **当前有效的专业指南、监管或公共卫生材料**（如 CDC、NHS、WHO）
2. **同行评议研究、系统综述和原始研究**
3. **有明确理论边界的专业实践框架**（如 Gottman 方法、NVC 非暴力沟通）
4. **古籍、文学、回忆录和大众作品**——只作理解、对照或叙事材料，不单独作为决策证据
5. **模型综合判断**——必须明确标注为综合，不是外部事实

## 知识条目注册格式

每条知识记录以下字段：

| 字段 | 说明 |
|------|------|
| claim_id | 唯一标识 |
| 主题 | 知识所属领域 |
| 结论 | 该知识的核心主张 |
| 证据类型 | 来自证据层级的哪一级 |
| 样本与文化范围 | 该知识在什么人群/文化中成立 |
| 相关性限制 | 相关 ≠ 因果 |
| 适用条件 | 什么情况下该知识适用 |
| 禁忌条件 | 什么情况下该知识不适用或可能有害 |
| 潜在风险 | 误用该知识可能导致的问题 |
| 来源 URL | 主要来源链接 |
| 出版/更新日期 | 来源的时效性 |
| 最后核验日期 | love-me 上次确认该知识仍然有效的日期 |
| 是否涉及法律/医疗/性健康/危机 | 是否需要特殊谨慎 |
| 需要联网刷新 | 该知识是否容易变化 |

## 关键知识条目

### 关系信号与判断

**claim_id**: SIG-001
**主题**: 关系中的兴趣信号
**结论**: 持续且有成本的行为（主动联系、履行约定、把对方纳入计划、冲突后修复）是比单次行为更可靠的兴趣信号。单次热情、礼貌、暧昧语句和表情属于弱信号。
**证据类型**: 3（Gottman 方法、关系科学文献）
**样本与文化范围**: 主要基于西方伴侣研究，在中国文化语境下需注意表达方式的差异
**相关性限制**: 这些信号模式是统计规律，不能确定个体情况
**适用条件**: 可用于帮助用户区分"有依据的信号"和"愿望投射"
**禁忌条件**: 不得把信号数量机械化，不得设定固定阈值判定"爱不爱"
**潜在风险**: 用户可能用此框架过度分析每一个行为，增加焦虑
**最后核验日期**: 2026-08-05
**需要联网刷新**: false

### 星座与关系

**claim_id**: ASTRO-001
**主题**: 星座在关系判断中的使用边界
**结论**: 星座（太阳/月亮/上升星座、合盘等）可以作为了解沟通风格偏好和潜在摩擦点的参考框架，但不能预测关系结局、判定"合不合适"、或替代实际行为观察
**证据类型**: 5（模型综合判断，基于星座系统的符号学性质）
**样本与文化范围**: 适用于熟悉并自愿使用星座框架的用户
**相关性限制**: 星座系统是符号和原型语言，不是经验科学。没有同行评议研究支持星座预测关系结局的有效性
**适用条件**: 用户明确要求、场景自然需要、作为沟通风格讨论的起点
**禁忌条件**: 不得用于重大关系决策的唯一依据；不得当作人格诊断工具
**潜在风险**: 巴纳姆效应（模糊描述被当作准确）、刻板印象强化、自我实现的预言
**最后核验日期**: 2026-08-05
**需要联网刷新**: false

### MBTI 与关系

**claim_id**: MBTI-001
**主题**: MBTI 在关系中的使用边界
**结论**: MBTI 认知功能栈可以帮助理解不同人的沟通偏好和信息处理方式差异。但 MBTI 不能判定"哪种类型最适合你"、预测关系成功、或替代对具体人的观察
**证据类型**: 2（MBTI 在人格心理学中的信效度存在学术争议；认知功能角度的应用属于实践框架）
**样本与文化范围**: MBTI 的常模主要基于美国样本
**相关性限制**: 人格类型是倾向而非决定因素；两个人如何相处比各自是什么类型重要得多
**适用条件**: 用户提供 MBTI 信息或主动询问，用于理解沟通差异
**禁忌条件**: 不得将 MBTI 用于筛选对象、判定兼容性或预测关系结局
**潜在风险**: 类型标签固化为刻板印象，忽视个体的复杂性和成长能力
**最后核验日期**: 2026-08-05
**需要联网刷新**: false

### 八字与关系

**claim_id**: BAZI-001
**主题**: 八字在关系中的使用边界
**结论**: 八字（日主、五行、流年大运等）可以作为理解性格倾向和人生阶段的参考框架。合婚/合八字不能替代实际相处中的观察和沟通
**证据类型**: 5（模型综合判断；八字是中国传统文化中的命理系统，不属于经验科学）
**样本与文化范围**: 适用于熟悉并自愿使用八字框架的华语用户
**相关性限制**: 八字系统是符号和类比语言，没有同行评议研究支持其预测关系的有效性
**适用条件**: 用户明确提供八字信息或主动要求分析
**禁忌条件**: 不得用于重大关系决策的唯一依据；不得推算"正缘"时间并建议用户被动等待
**潜在风险**: 宿命论思维（"八字不合就放弃"替代了真实沟通）、焦虑（"流年不利"被当作不可改变的厄运）
**最后核验日期**: 2026-08-05
**需要联网刷新**: false

## 来源刷新规则

- 涉及法律、医疗、性健康或危机资源的知识条目必须每6个月联网核验
- 涉及关系科学研究的条目可以离线使用，但在被用户质疑或出现明显过时信号时应核验
- 热线电话、求助机构、法律条文必须在每次实际引用前核验当前有效性
- 古籍条目不在此注册表中（见 `references/past-wis-bridge.md`）
