# Source Registry — 知识来源注册表

read-between 的知识主张遵循证据层级。本文件记录重要知识条目的来源、适用范围和核验状态，确保每一条可被追溯和推翻。

## 证据层级

1. **当前有效的专业指南、监管或公共卫生材料**（如 CDC、NHS、WHO）
2. **同行评议研究、系统综述和原始研究**
3. **有明确理论边界的专业实践框架**（如 Gottman 方法、NVC 非暴力沟通）
4. **古籍、文学、回忆录和大众作品**——只作理解、对照或叙事材料，不单独作为决策证据
5. **模型综合判断**——必须明确标注为综合，不是外部事实

## 知识条目注册格式

每条知识记录以下字段：

| 字段 | 说明 |
|------|------|
| claim_id | 唯一标识 |
| 主题 | 知识所属领域 |
| 结论 | 该知识的核心主张 |
| 证据类型 | 来自证据层级的哪一级 |
| 样本与文化范围 | 该知识在什么人群/文化中成立 |
| 相关性限制 | 相关 ≠ 因果 |
| 适用条件 | 什么情况下该知识适用 |
| 禁忌条件 | 什么情况下该知识不适用或可能有害 |
| 潜在风险 | 误用该知识可能导致的问题 |
| 来源 URL | 主要来源链接 |
| 出版/更新日期 | 来源的时效性 |
| 最后核验日期 | read-between 上次确认该知识仍然有效的日期 |
| 是否涉及法律/医疗/性健康/危机 | 是否需要特殊谨慎 |
| 需要联网刷新 | 该知识是否容易变化 |

### 关系信号与判断

**claim_id**: SIG-001
**主题**: 关系中的兴趣信号
**结论**: 持续且有成本的行为（主动联系、履行约定、把对方纳入计划、冲突后修复）是比单次行为更可靠的兴趣信号。单次热情、礼貌、暧昧语句和表情属于弱信号。
**证据类型**: 3（有明确理论边界的专业实践框架，如 Gottman 方法）
**样本与文化范围**: 主要基于西方伴侣研究；在非西方文化语境中，兴趣表达方式（直接/间接、言语/行动）可能存在系统性差异
**相关性限制**: 这些信号模式描述的是统计关联，不能确定个体情况
**适用条件**: 可用于帮助用户区分"有依据的行为模式"和"愿望投射"
**禁忌条件**: 不得把信号模式机械化——"强信号"是一个程度判断而非计数任务
**潜在风险**: 用户可能用此框架过度分析每一个行为，增加焦虑而非减少不确定性
**来源 URL**: https://www.gottman.com/about/the-gottman-method/
**出版/更新日期**: Gottman 方法的研究基础始于 1970s，持续更新中
**最后核验日期**: 2026-08-06
**需要联网刷新**: false

### 星座与关系

**claim_id**: ASTRO-001
**主题**: 星座在关系判断中的使用边界
**结论**: 星座（太阳/月亮/上升星座、合盘等）可以作为了解沟通风格偏好和潜在摩擦点的参考框架，但不能预测关系结局、判定"合不合适"、或替代实际行为观察
**证据类型**: 5（模型综合判断——星座是符号和原型语言系统，不是经验科学）
**样本与文化范围**: 适用于熟悉并自愿使用星座框架的用户；星座的符号含义在不同文化传统（西方占星/印度吠陀占星/中国星官）中存在显著差异
**相关性限制**: 星座系统通过巴纳姆效应（模糊描述被当作准确）和确认偏误产生"准确"的主观感受；没有同行评议研究支持星体位置预测关系结局的有效性
**适用条件**: 用户明确要求、场景自然需要、作为沟通风格讨论的启发式起点
**禁忌条件**: 不得用于重大关系决策的唯一依据；不得当作人格诊断工具；不得将符号描述写成对具体人的性格事实陈述
**潜在风险**: 巴纳姆效应（模糊描述被当作准确）、刻板印象强化、自我实现的预言
**来源 URL**: 该条目为关于星座使用边界的元判断，不是星座体系内的知识主张。关于星座的符号学性质，参见 e.g., Campion, N. (2012). Astrology and Cosmology in the World's Religions. NYU Press.
**出版/更新日期**: 2026-08-06（模型综合判断的编写日期）
**最后核验日期**: 2026-08-06
**需要联网刷新**: false

### MBTI 与关系

**claim_id**: MBTI-001
**主题**: MBTI 在关系中的使用边界
**结论**: MBTI 认知功能栈可以帮助理解不同人的沟通偏好和信息处理方式差异。但 MBTI 不能判定"哪种类型最适合你"、预测关系成功、或替代对具体人的观察
**证据类型**: 5（模型综合判断——read-between 将 MBTI 作为沟通风格偏好的启发式框架使用，不将其作为经验验证的心理测量工具。MBTI 在学术人格心理学中的信效度存在争议：其支持者认为它提供了有用的偏好描述；批评者指出其重测信度不足、四维度的统计结构未得到因子分析的一致支持）
**样本与文化范围**: MBTI 的常模主要基于美国样本；在不同文化中四字母偏好的分布和含义可能存在差异
**相关性限制**: 人格偏好倾向不是行为的决定因素；两个人如何相处比各自是什么类型重要得多
**适用条件**: 用户提供 MBTI 信息或主动询问，用于理解沟通差异的启发式讨论

**潜在风险**: 类型标签固化为刻板印象（"INFP就是情绪化"），忽视个体的复杂性和成长能力
**来源 URL**: Myers, I. B., & Myers, P. B. (1995). Gifts Differing: Understanding Personality Type. Davies-Black Publishing. 关于信效度的学术批评，参见 e.g., Pittenger, D. J. (1993). "Measuring the MBTI… And Coming Up Short." Journal of Career Planning and Employment, 54(1), 48-52.

### 八字与关系

**claim_id**: BAZI-001
**主题**: 八字在关系中的使用边界
**结论**: 八字（日主、五行、流年大运等）可以作为理解性格倾向和人生阶段的参考框架。合婚/合八字不能替代实际相处中的观察和沟通
**证据类型**: 5（模型综合判断——八字是中国传统文化中的命理符号系统，不属于经验科学。其内部使用干支、五行、十神等类比语言描述气质倾向和人生阶段）
**样本与文化范围**: 适用于熟悉并自愿使用八字框架的华语用户；八字体系深深嵌入中国传统文化语境，其符号含义在非华语文化中可能无法直接迁移
**相关性限制**: 八字系统是类比和符号语言，通过确认偏误和主观解释产生"准确"的感受。没有同行评议研究支持干支组合预测或决定人格、关系或人生事件的有效性
**适用条件**: 用户明确提供八字信息或主动要求分析
**禁忌条件**: 不得用于重大关系决策的唯一依据；不得推算"正缘"时间并建议用户被动等待；不得将五行/日主的类比描述写成对具体人的性格事实陈述
**潜在风险**: 宿命论思维（"八字不合就放弃"替代了真实沟通与行为观察）、焦虑（"流年不利"被当作不可改变的厄运）
**来源 URL**: 该条目为关于八字使用边界的元判断。八字作为传统文化知识体系，其历史文献基础包括《渊海子平》（宋代）、《三命通会》（明代）等。现代关于八字作为文化符号的分析，参见 e.g., Chao, Y. L. (1946). "The Chinese Art of 'Reading Fate.'" Harvard Journal of Asiatic Studies, 9(3/4), 249-283.（历史文献回顾，不是对八字预测有效性的经验验证）
**出版/更新日期**: 本条目编写 2026-08-06
**最后核验日期**: 2026-08-06
**需要联网刷新**: false

## 来源刷新规则

- 涉及法律、医疗、性健康或危机资源的知识条目必须每6个月联网核验
- 涉及关系科学研究的条目可以离线使用，但在被用户质疑或出现明显过时信号时应核验
- 热线电话、求助机构、法律条文必须在每次实际引用前核验当前有效性
- 古籍条目现已在上述 CLASSIC-001 至 CLASSIC-010 中注册（另见 `references/classical-interpretation.md`）

### 诗经

**claim_id**: CLASSIC-001
**主题**: 先秦情诗与感情表达
**结论**: 《诗经》是中国爱情文学的源头，收录了从西周到春秋时期的305篇诗歌。国风中的情诗涵盖了单相思、追求、约会、新婚、思念、离别、弃妇等完整的感情光谱。这些诗歌可以作为用户感受的"镜子"——帮助命名和理解当下的情绪体验。
**证据类型**: 4（古籍、文学——只作理解或叙事材料，不单独作为决策证据）
**样本与文化范围**: 先秦时期中原地区的民间与贵族诗歌；反映的是公元前11世纪至前6世纪的恋爱与婚姻观念
**相关性限制**: 先秦的婚恋制度（父母之命、媒妁之言、一夫多妻）与现代根本不同。情诗中的情感可以共鸣，但制度不能迁移
**适用条件**: 用户需要感受被命名、被理解时；用户主动寻求古典情感参照时
**禁忌条件**: 不得用《诗经》中的婚恋规范来建议用户的现实行为；不得把"君子""淑女"的古代标准当作当代标准
**潜在风险**: 部分诗篇（如弃妇诗）反映了古代女性在婚姻中的弱势地位，误用可能强化性别刻板印象
**来源 URL**: 殆知阁 daizhige.org 开放语料库 (github.com/frankslin/daizhigev20)
**出版/更新日期**: 原文成书于先秦（公元前11世纪-前6世纪）；殆知阁数字化版本最后更新 2018-11-26
**最后核验日期**: 2026-08-07

### 菜根谭

**主题**: 人情进退与处世智慧
**结论**: 《菜根谭》是明代洪应明所著的清言小品，分修身、应酬、评议、闲适、概论五部分，精炼地阐述了人情世故中的进退分寸、情绪管理和自省之道。是10部文本中最短、最直接可用的人情指南。
**证据类型**: 4（古籍、文学——只作理解或叙事材料，不单独作为决策证据）

**禁忌条件**: 不得用"忍"来合理化不健康的自我牺牲；不得将消极避世放大为"遇到困难就该退"
**潜在风险**: 过度强调退让和忍耐可能延迟用户设立健康边界

### 庄子

**claim_id**: CLASSIC-007
